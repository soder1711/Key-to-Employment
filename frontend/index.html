Weekly plan

admin

Drag a person from the top onto a task to give it a person. If the same task (same time) exists on this weekday in following weeks, a popup asks whether to apply the person to this day only or to all following weeks — with an option to override weeks that already have a person. Points are added up automatically. Click a task for options. One day is shown at a time — use the arrows (or ← → keys) to see another day. "Delete + following weeks" removes every later occurrence with the same task, same time and same weekday; anything else is kept. Use "Manage tasks" to create new tasks or delete them from the list.
